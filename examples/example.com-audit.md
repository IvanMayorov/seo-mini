## Проблемы и примеры

### [Высокий] Вариант адреса сайта открывается без редиректа (3)

Один сайт виден по нескольким адресам. Настройте 301 на основное зеркало.

- `#4` http://example.com/ — ответ 200
- `#5` http://www.example.com/ — ответ 200
- `#3` https://www.example.com/ — ответ 200

### [Высокий] Нет H1 (1)

Добавьте один основной заголовок страницы.

- `#9` https://example.com/

### [Средний] Нет canonical (1)

Добавьте канонический адрес, особенно на страницах с параметрами.

- `#6` https://example.com/

### [Средний] Нет description (1)

Заполните: текст может попасть в сниппет.

- `#8` https://example.com/

### [Средний] Нет robots.txt (1)

Создайте файл и укажите в нём служебные разделы и sitemap.

- `#1` https://example.com/robots.txt — ответ: 404

### [Средний] Нет sitemap (1)

Создайте sitemap.xml и добавьте его в Вебмастер и Search Console.

- `#2` https://example.com/sitemap.xml

### [Низкий] Мало текста (менее 100 слов) (1)

Для карточек товара это бывает нормально; проверьте важные страницы.

- `#10` https://example.com/ — 25 слов
